OpalVoIP

Open Phone Abstraction Library

Open source C++ for voice, video, and real-time communication. OPAL presents SIP, H.323, and the media that travels with them as one call model. PTLib is the portable library it is built on.

OPAL on GitHub PTLib on GitHub

Repositories

Both libraries are in the OpalVoip organisation on GitHub. Clone PTLib first, then OPAL.

OPAL

Call control, signalling, RTP media, and codec plugins. Applications link this library and build it against PTLib.

https://github.com/OpalVoip/opal

PTLib

Portable Tools Library. Threading, networking, and I/O for Unix, macOS, and Windows. OPAL requires a PTLib build.

https://github.com/OpalVoip/ptlib

What the libraries cover

  • Signalling

    SIP and H.323, including the supplementary services and NAT extensions that sit with H.323, plus SDP for session description.

  • Media

    RTP and RTCP, audio and video codec plugins, mixing, and secure media when the build has SRTP.

  • Platforms

    Windows through the Visual Studio projects. Linux, macOS, and other Unix systems through the makefiles in each tree.

Get the source

Build PTLib, then build OPAL against that PTLib. Each repository carries the build instructions for its tree.

git clone https://github.com/OpalVoip/ptlib.git
git clone https://github.com/OpalVoip/opal.git
